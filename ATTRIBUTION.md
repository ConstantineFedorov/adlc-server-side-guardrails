## Scope of this repository

This repository separates the Homework 3 assessment, supporting documentation and six modified guardrail source files from the upstream lab. The implementation files are an overlay/patch intended to be reviewed and applied to a compatible upstream checkout; this repository is not currently a complete standalone package and does not include the full upstream runtime, configuration, dependencies or test corpus.

The recorded regression result (150/208 passed) comes from a local run in the lab environment. It has not been independently reproduced from this repository.
