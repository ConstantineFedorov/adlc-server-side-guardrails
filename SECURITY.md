# Security Policy

## Scope

This is an educational security assessment of server-side guardrails in a local LLM-agent lab. It is not a production guardrail framework and does not certify that an agent is secure.

## Reporting a concern

Please do not post secrets, credentials, personal data or private logs in a public issue. Contact the repository owner through a private GitHub communication channel and include:

- affected file or control;
- steps to reproduce in an authorized lab;
- observed and expected behavior;
- minimal evidence with secrets and personal data removed.

## Responsible testing

- Test only systems you own or are explicitly authorized to assess.
- Use isolated environments and harmless canary values.
- Do not commit API keys, tokens, credentials, local model files or unredacted logs.
- Share only the evidence needed to explain a finding.
- Check upstream licenses and corpus terms before redistributing third-party material.
